# openless-pr-evidence-windows-capsule-contract

PR review evidence for the OpenLess Windows capsule contract work (issue #498).
This repository holds capture artifacts (screenshots + hit-test JSON) that back the
PR body and are intentionally kept out of the product branch.

## What is this

- `windows-capsule-contract-498/` — evidence bundle for issue/PR 498:
  - `recording-capsule-host-crop.png` / `translation-capsule-host-crop.png` — capsule host crops
  - `recording-hit-test.json` / `translation-hit-test.json` — hit-test geometry data
  - `accepted-recording-translation-comparison.png` — accepted comparison shot
  - `README.md` — capture metadata (date, DPI, source issue)

## How to use

This is an evidence archive, not a runnable project. There is no build or test step.
Open the PNGs to review capsule geometry and inspect the hit-test JSON for coordinates.
